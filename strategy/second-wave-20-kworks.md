## Как использовать вторую волну

### Не публиковать 20 одинаковых вариаций

Каждая карточка должна отличаться buyer intent, а не только перестановкой слов в title.

### Где особенно важен proof

- speed — screenshot `до/после`;
- QA — пример bug-report;
- desktop — реальный интерфейс приложения;
- plugin — короткая demo/gif или settings screen;
- AI — схема workflow + реальный экран результата.

### Где можно быстро получить первый заказ

По наблюдаемой выдаче особенно подходят для low-friction entry:

- VBA / Excel;
- Google Sheets;
- plugin setup/fix;
- QA сайта;
- broken links/resources;
- small deploy/configuration.

### Где держать высокий потолок

- custom desktop software;
- AI assistant / AI seller;
- WordPress plugin development;
- complex import/export;
- end-to-end deploy and integration.

## Правило запуска

После публикации карточки не считать её «готовой навсегда». Для каждой карточки вести:

`views → messages → orders → average check → extras → review → repeat`.

Если есть просмотры, но нет сообщений — менять title/cover/offer. Если сообщения есть, но нет заказов — смотреть scope/price/trust/questions. Если заказы есть — размножать соседние buyer intents.
