# Финальный профиль Kwork — v1

Статус: готово к переносу в профиль после seller onboarding.

## Позиционирование

**Разработка и автоматизация: сайты, боты, API, CRM, скрипты, AI и веб-сервисы**

Задача позиционирования — не зафиксировать одну нишу, а дать заказчику понять, что можно прийти как с небольшой технической правкой, так и с полноценной системой.

## Описание профиля — основной вариант

Решаю прикладные задачи разработки для бизнеса: от небольшой правки сайта или скрипта до Telegram-бота, CRM-интеграции, автоматизации и полноценного веб-сервиса.

Могу подключиться к существующему проекту, найти и исправить проблему, добавить функционал или разработать решение с нуля.

Что можно поручить:
- доработку и исправление сайтов;
- WordPress, Bitrix и PHP/backend-задачи;
- Telegram-ботов и автоматизацию;
- API, webhooks и интеграции сервисов;
- CRM и системы онлайн-записи;
- Python/PHP-скрипты, парсеры и обработку данных;
- личные кабинеты, админ-панели и SaaS/MVP;
- серверные задачи, deploy, Linux/Nginx/Docker;
- AI/LLM-интеграции в существующие процессы.

Есть коммерческий production-опыт в проектах автоматизации бизнеса и CRM, а также опыт разработки полноценных собственных продуктов с backend, пользовательскими кабинетами, админ-панелями, desktop-приложением и realtime-взаимодействием.

Работаю по понятной схеме: уточняем конечный результат → фиксируем объём и стоимость → реализую → проверяю → сдаю готовый результат.

Если задача сформулирована не техническим языком — это нормально. Опишите, что сейчас работает не так или какой результат нужен. Сам задам необходимые вопросы и предложу вариант реализации.

**Стек:** PHP/Laravel • Python • JavaScript • SQL • REST API • WordPress/Bitrix • Linux/Docker

## Аватар

Не оставлять букву `T`.

Требования:
- реальная фотография;
- лицо крупно и читается на маленькой иконке;
- простой фон;
- без мелкого текста и логотипов;
- нейтральный профессиональный вид.

## Что НЕ писать

- «начинающий фрилансер»;
- длинную биографию и хронологию работы;
- список из десятков библиотек;
- акцент на использовании Codex/AI как замене компетенции;
- «делаю абсолютно всё» без структуры;
- полное резюме Rubikon.

## Доказательства, которые должны поддерживать профиль

На старте профиль должен быть подкреплён портфолио минимум из следующих классов:
- полноценный SaaS / кабинет / админка — Skillcue;
- CRM / расписание / запись — RuviCRM;
- API/CRM/booking integration — Rubikon experience;
- Telegram bot / automation case;
- внешний сервис ↔ CRM / webhook automation.

После первых заказов Kwork добавлять в портфолио micro-cases, максимально близкие к конкретным кворкам: WordPress before/after, API flow, parser output, Telegram notification и т. п.
