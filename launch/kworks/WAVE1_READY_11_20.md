# Общие правила перед публикацией Wave 1

1. Не копировать тексты конкурентов дословно.
2. В каждом кворке проверить, что base scope можно выполнить без экономически опасного scope creep.
3. Не обещать конкретный срок, если в форме Kwork минимальный/максимальный срок отличается — адаптировать.
4. Для 18–20 до заказа обязательно предварительное сообщение/оценка scope.
5. После первых 3–5 заказов пересмотреть цены и extras по фактической трудоёмкости.
6. Если Kwork не позволяет выбранную рубрику, выбирать ближайшую buyer-facing категорию, а не прятать intent ради идеальной классификации.
